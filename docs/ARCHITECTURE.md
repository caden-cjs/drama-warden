# 架构方向

## 责任边界

追更核心管理节目、季、集、存储资产、缺集判断、事件状态和工作流顺序。外部服务通过插件契约访问。

插件负责服务连接、认证、调用和统一结构转换。插件不直接决定某个追更事件应当标记为成功、跳过或失败，也不绕过核心状态机执行额外写入。

## 插件能力

计划支持的插件能力包括：

- metadata-provider：节目详情、搜索和集数清单
- resource-provider：分享资源搜索和枚举；候选通过追更预览核对
- storage-provider：列出、保存、移动、命名及显式删除策略
- indexer：媒体索引刷新
- notification-provider：状态和异常通知
- subtitle-provider：字幕搜索与获取
- workflow-provider：受控的工作流定义和执行

插件按 API v2 契约校验。运行时按能力和语义域查找插件，kind 只用于管理分组；管理页面可查看运行时注册的 manifest 和能力、启停插件、调整同类顺序、运行自检及调用插件的 reset 生命周期钩子。启用状态和顺序保存在 `application_setting`；插件凭据由部署环境管理，可信插件模块列表可放在 YAML 或环境变量中。业务规则仍由追更核心掌握。插件会在应用进程内执行；加载失败或契约校验失败会阻止服务启动。

非敏感运行配置从 `config/config.yaml` 加载，缺省时使用 `config/config.example.yaml`；非空环境变量优先覆盖对应 YAML 字段。仅允许列入配置 schema 的字段，密钥和凭据不能放进 YAML。Compose 在启动容器时只读挂载 `config/`；Git、Docker 构建上下文和 npm 包边界排除 `config/` 中除公开示例外的本地配置文件。

内置 provider 由服务组合入口装配；`backend/core/`、`backend/api/` 和 `backend/db/` 不直接依赖 provider 实现。`npm run check:architecture` 扫描这些目录的静态与字面量动态 ESM 导入；同时禁止插件反向导入业务、数据库或部署配置，禁止通用宿主绑定内置 provider、provider 跨目录直接互调，以及 SDK 导入应用内部实现。新增依赖模式需同步扩展检查器；这不是运行时沙箱。检查由 `npm run check` 和 CI 执行。

## 数据模型

内部节目、季、集 ID 由本项目生成。TMDB、TVmaze 等外部 ID 作为来源映射保存。网盘文件作为资产关联到逻辑剧集，允许同一集存在多个版本并显式记录冲突。

SQLite 是默认持久化方案，MySQL 作为可选驱动。数据库迁移应可重复执行；导入历史数据前需提供只读预览和逐项校验。

仓库只依赖异步数据库端口：`get/all/run/transaction/close`。驱动适配器负责连接、排队和事务边界，业务仓库不接触 `better-sqlite3` 的 statement 对象。SQLite 为默认驱动；MySQL 适配器使用独立连接池、版本表和分阶段迁移，并在涉及 upsert 和时间表达式的仓库中选择 MySQL 方言 SQL。MySQL 8.4 集成测试已验证 schema 初始化和重复启动、节目与季集仓库读写、字幕任务认领、插件调用记录的写入/查询/保留裁剪、完整资产扫描，以及通过模拟存储和索引端口执行的追更成功与失败恢复路径。该验证不覆盖真实供应商 CLI、外部字幕 API、生产凭据或备份恢复演练。

## 当前实现状态

当前已实现 SQLite 和 MySQL v4 schema、可重入版本迁移、异步数据库端口、节目和元数据身份仓库、季集/资产仓库、追更事件、字幕任务、非秘密应用设置及插件调用审计仓库。元数据服务通过注入的插件列表和 invoke 端口做 first-sufficient 回退；TVmaze 默认注册，TMDB 在配置 `TMDB_API_KEY` 后注册并排在其前。认证后的元数据搜索返回 provider 候选，身份关联仍由用户确认。追更计划按季区分缺集、资产冲突、已播和未来排期，并且只把分享清单中可识别的未来单集加入候选。API v2 插件契约、宿主、生命周期事件、持久调用审计钩子和 ESM/npm 加载器已接入服务启动；HTTP 层提供 Bearer 令牌保护的节目、元数据身份、插件管理、插件调用记录、追更事件、字幕任务和运行设置 API，以及公开的数据库健康检查。插件管理 API 只保存启用状态和顺序，不接受或回显凭据。

插件调用日志只记录插件、能力、调用来源、关联 ID、成功状态、稳定错误码、耗时和时间，不保存输入、输出、原始错误消息或凭据。`plugin_call_log` 启动时和每累计 100 次调用后裁剪为最新 10,000 条；便携 v4 导出包含该记录，v3 导入会以空审计表升级。

追更核心支持资源插件候选搜索、单分享预览、排队和手动处理单个事件。资源搜索只返回候选并附带预览，不创建事件、不保存媒体。周期扫描默认关闭；启用后每个节目/存储位置每轮最多排队一个符合条件的候选，实际处理还要求单独启用自动处理；搜索结果不完整时不自动排队。处理阶段复核分享清单中的选定文件 ID、目标目录完整性及本次保存产生的文件集合，再执行季目录整理、canonical 命名、资产增量同步和可选索引刷新。显式存储扫描将完整递归清单同步为资产快照；截断清单只增量记录可见项，不标记未见资产缺失。事件进入 `processed` 与写入占位完成在同一数据库事务中提交，避免留下事件与占位状态不一致的中间状态。存储写入开始后的失败会将占位标为 uncertain，API 普通重试会拒绝带占位的事件；事件通知在状态持久化后发布，通知失败不会反向修改事件终态。仓库内置本地文件系统存储和本地资源搜索插件作为参考适配器；其他资源来源通过 `resource-provider` 契约接入，目标存储类型由核心传入，候选仍须经目标 storage-provider 的分享清单与追更预览验证。

进程中断后遗留的 `processing` 事件，以及写入结果不确定的 `failed` 事件，可通过受保护的 recovery API 显式复核。复核会拒绝仍由当前服务进程处理的事件；完整目标清单中能唯一匹配全部候选文件时，可继续命名、同步资产、刷新索引并完成事件。事件没有持久化转存前目录快照或内容哈希，因此名字与大小只能筛选候选，完成前还要求操作人确认文件属于本事件。确认无输出时，reserved/uncertain 占位只在完整目录核对后转为 reserved 并开放人工重试；部分文件、歧义或不完整清单会保持原状态，要求人工整理后再次复核。恢复期间只支持单个应用实例连接同一数据库。

可选 SmartStrm indexer 通过独立 `indexer` capability 接收追更完成后的索引刷新请求。当前适配器只操作环境变量指定的单一任务；只有 HTTP 2xx 且响应体明确包含 `success: true` 才确认刷新已接受。网络结果不确定时不自动重试，追更事件保持未完成以便核查。

字幕搜索和下载由 `subtitle-provider` 插件提供，核心按插件注册顺序回退并独立校验集号。SQLite/MySQL v2 队列按存储位置、季、集去重，支持限次退避和随机 lease token；调用存储插件写入前会持久化副作用边界。中断或响应不确定的写入会进入 `uncertain`，不会自动再次写入；旧 worker 不能借用新 worker 的任务认领继续写入。当前 OpenSubtitles 需 API key，Assrt 网页搜索需显式启用。本地存储支持受大小和路径约束的独占 sidecar 创建；夸克和 115 尚不提供该可选能力。

可选 MCP 通过独立 stdio 进程连接受 Bearer 令牌保护的 REST API。它复用 API 的状态转换和插件边界；MCP SDK 与 Zod 是 optional dependencies，普通 HTTP 服务启动不会导入 MCP 模块。

Vue 3 管理面板通过同源 REST API 读取节目、事件、插件和自动化状态。更新记录从持久化 `update_event` 终态派生；插件页另有可筛选的持久调用审计记录。浏览器只保存 API Bearer 令牌；节目关联、存储扫描和追更预览调用现有 API。事件处理会先显示写入确认。字幕任务页支持状态查询、安全重试和单集排队。插件页可启停、排序、自检和调用 reset hook；重置动作由插件代码决定。设置页可调整数据库保存的追更调度开关、间隔和自动处理选项；自动处理会让定时工作流写入媒体，并需在面板显式确认。数据库连接、令牌、provider 凭据与插件路径仍由部署环境管理，不通过 API 回显。

SQLite 目录同步只在调用方明确传入完整快照时标记未见资产缺失；集数冲突按路径资产数显式记录。MySQL 初始化只创建独立 schema，不导入 SQLite 现存数据。其余内容是目标边界，完成并验证后才会成为可用功能。
